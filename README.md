# 🛒 E-Commerce Sales Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing e-commerce sales data using Microsoft Power BI. The dashboard provides interactive visualizations to understand sales performance, profit trends, customer behavior, product categories, and payment methods.

The main objective is to transform raw sales data into meaningful insights that can help businesses make better decisions.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query (Data Cleaning & Transformation)
- DAX (Data Analysis Expressions)
- Data Visualization
- CSV Dataset

## 📂 Dataset Description
The project uses two CSV files:

**1. Orders.csv**
- Order ID
- Order Date
- Customer Name
- State
- City

**2. Details.csv**
- Order ID
- Amount
- Profit
- Quantity
- Category
- Sub-Category
- Payment Mode

Both datasets are connected using the Order ID field.

## 📊 Dashboard Features

- **Sales KPIs:** Total sales amount, quantity, average order value (AOV), and total profit.
- **Quarterly Analysis:** Interactive quarter filters to analyze performance.
- **Profit by Month:** Monthly profit comparison.
- **Category Analysis:** Quantity distribution across product categories.
- **Payment Mode Analysis:** Orders and quantity by payment methods.
- **State-wise Sales:** Comparison of sales across different states.
- **Customer Analysis:** Sales contribution by individual customers.
- **Sub-Category Profit:** Profit comparison across product sub-categories.

## 🔍 Key Insights
- Monthly profit can be compared to identify changes in performance.
- Category-wise analysis helps understand product demand.
- Payment mode analysis shows customer payment preferences.
- State-wise sales comparison highlights important sales regions.
- Sub-category analysis helps identify products contributing more profit.

## 🚀 How to Use
1. Download or clone this repository.
2. Open the Power BI `.pbix` file using Microsoft Power BI Desktop.
3. Make sure the CSV datasets are available.
4. Explore the dashboard using the quarter and other filters.
5. Interact with charts to analyze sales and profit performance.
